## P-003 §9.2 上一个里程碑的 PR 未合并时的分支策略

- **建议增加**：“上一个里程碑的 PR 尚未合并时，新里程碑分支基于上一分支创建（堆叠 PR），PR 的 base 指向上一分支；上一个合并后再改到 main。”
