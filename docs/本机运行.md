# 在本机运行后端

> 负责人决定（2026-10-12）：先在本机运行，暂不购买云服务器。以下步骤已在 macOS 联动的 Linux 环境中实测通过；在 Mac 终端里操作完全相同。

## 1. 准备工具（只需一次）

- **uv**：管理 Python 和依赖。Mac 上执行 `brew install uv`，或参考 <https://docs.astral.sh/uv/>。uv 会自动下载所需的 Python（≥ 3.11），不需要另外安装。
- **Node.js ≥ 20 + pnpm**：只有运行 legacy 对拍测试时需要。启用 pnpm：`corepack enable`。

## 2. 安装依赖

```bash
cd ~/项目/综合测评计算网站
uv sync                                   # Python 依赖（版本由 uv.lock 锁定）
(cd tests/parity && pnpm install)         # 可选：对拍测试用的 jsdom
```

## 3. 配置

```bash
cp deploy/.env.example .env
python3 -c "import secrets; print(secrets.token_urlsafe(48))"   # 生成密钥，填到 .env 的 ZONGCE_JWT_SECRET
```

`.env` 已被 `.gitignore` 排除，**不要提交**。默认数据库是 `data/zongce.sqlite3`，上传的材料放在 `uploads/`，这两个目录也都被排除在仓库之外。

## 4. 初始化

```bash
uv run zongce init-db                                  # 建表（Alembic 迁移到最新版本）
uv run zongce create-admin --username admin            # 创建学院管理员，按提示输入密码
uv run zongce load-rules rules/ujn-v1.json --catalog rules/ability-catalog-xxgc-2020.json
```

## 5. （可选）生成合成演示数据

```bash
uv run python scripts/gen_fake_data.py --out data/demo    # 生成 users.xlsx、college.xlsx（学号以 TEST 开头）
```

用管理员账号把 `users.xlsx` 导入到“批量导入账号”，再把 `college.xlsx` 导入到某个学年的“导入学院成绩表”，就能直接核算、排名、发布公示。`data/` 已被 `.gitignore` 排除。

## 6. 启动

```bash
uv run zongce serve            # 默认 http://127.0.0.1:8000
```

浏览器打开 <http://127.0.0.1:8000/api/v1/docs>：点右上角 **Authorize**，填入登录接口返回的 `access_token`，就能直接试用所有接口。

## 7. 前端（可选，页面开发中）

```bash
cd frontend && corepack enable && pnpm install && pnpm dev    # http://localhost:5173
```

前端开发服务器会把 `/api` 代理到本机后端，不需要配置跨域。目前只有登录、改密和占位页，正式页面等组件库选定后实现（见 `frontend/README.md`）。

## 8. 一个学年的典型流程

| 步骤 | 角色 | 接口 |
|---|---|---|
| 新建学年并关联规则版本 | 学院管理员 | `POST /api/v1/years` |
| 批量导入账号（表头：学号、姓名、班级、角色） | 学院管理员 | `POST /api/v1/users/import` |
| 把随机初始密码发给学生；学生首次登录必须修改密码 | 学生 | `POST /api/v1/auth/change-password` |
| 开放申报 | 学院管理员 | `PATCH /api/v1/years/{id}/status` → `open` |
| 申报能力分、上传证明材料、提交 | 学生 | `POST /api/v1/declarations` 等 |
| 审核：通过 / 改分 / 驳回（理由必填） | 班级审核员、学院管理员 | `POST /api/v1/declarations/{id}/review` |
| 导入学院成绩表（GPA、第二课堂、公益劳动、体测、宿舍、思想品德评议） | 学院管理员 | `POST /api/v1/years/{id}/college-data/import` |
| 核算 | 学院管理员 | `POST /api/v1/years/{id}/scores/compute` |
| 查看排名、导出 Excel | 班级审核员（本班）、学院管理员 | `GET /api/v1/years/{id}/rankings[/export]` |
| 发布班级公示（默认 3 天） | 学院管理员 | `POST /api/v1/years/{id}/publications` |
| 提出异议 / 处理异议 | 学生 / 学院管理员 | `POST /api/v1/publications/{id}/appeals`、`POST /api/v1/appeals/{id}/resolve` |

## 9. 检查与测试

```bash
bash scripts/check.sh          # 与 CI 相同：ruff、mypy --strict、引擎（覆盖率 100% + 对拍）、后端（覆盖率 ≥ 80%）
```

## 注意

- 真实学生数据只在本机处理，不要提交进仓库、不要贴进对话（CLAUDE.md §11）。
- 修改了接口后，运行 `uv run zongce export-openapi docs/api/openapi.json` 更新接口文档；测试会检查它是否与代码一致。
