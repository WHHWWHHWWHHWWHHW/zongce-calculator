# 在本机运行后端

> 负责人决定（2026-10-12）：先在本机运行，暂不购买云服务器。以下步骤已在 macOS 联动的 Linux 环境中实测通过；在 Mac 终端里操作完全相同。

## 0. 一键演示（最快）

```bash
cd ~/项目/综合测评计算网站
bash scripts/local-demo.sh          # 首次运行会安装依赖、生成合成演示库，之后直接启动
```

- 浏览器打开 <http://127.0.0.1:8000>。后端同时提供页面和接口，只监听本机。
- 账号：学院管理员 `demo_admin`；班级审核员 `TEST01001`、`TEST02001`（同时是学生）；学生 `TEST01002` 起。共用密码在 `data/local-demo/演示密码.txt`。
- 演示库、密钥都在 `data/local-demo/`（已被 git 忽略），只有合成数据。`bash scripts/local-demo.sh --reset` 可以重新生成。
- 需要先装好 uv（`brew install uv`）；前端产物 `frontend/dist` 不存在时，脚本会用 pnpm 构建。
- Python 环境按系统分开存放（如 `.venv-darwin-arm64`），不影响其他环境里的 `.venv`。

## 1. 准备工具（只需一次）

- **uv**：管理 Python 和依赖。Mac 上执行 `brew install uv`，或参考 <https://docs.astral.sh/uv/>。uv 会自动下载所需的 Python（≥ 3.11），不需要另外安装。
- **Node.js ≥ 20 + pnpm**：只有运行 legacy 对拍测试时需要。启用 pnpm：`corepack enable`。

## 2. 安装依赖

```bash
cd ~/项目/综合测评计算网站
uv sync                                   # Python 依赖（版本由 uv.lock 锁定）
(cd tests/parity && pnpm install)         # 可选：对拍测试用的 jsdom
```

## 3. 配置

```bash
cp deploy/.env.example .env
python3 -c "import secrets; print(secrets.token_urlsafe(48))"   # 生成密钥，填到 .env 的 ZONGCE_JWT_SECRET
```

`.env` 已被 `.gitignore` 排除，**不要提交**。默认数据库是 `data/zongce.sqlite3`，上传的材料放在 `uploads/`，这两个目录也都被排除在仓库之外。

## 4. 初始化

```bash
uv run zongce init-db                                  # 建表（Alembic 迁移到最新版本）
uv run zongce create-admin --username admin            # 创建学院管理员，按提示输入密码
uv run zongce load-rules rules/ujn-v1.json --catalog rules/ability-catalog-xxgc-2020.json
```

## 5. （可选）生成合成演示数据

**一步生成演示库**（中期检查演示用）：

```bash
ZONGCE_DATABASE_URL=sqlite:///data/demo.sqlite3 uv run zongce seed-demo    # 按提示输入演示账号共用的密码
```

它会建表、导入规则，然后通过与真实操作相同的业务流程生成：学院管理员 `demo_admin`；2 个班、每班 30 名学生（学号以 TEST 开头，每班第 1 名同时是班级审核员）；学院成绩表；每班 8 条申报，覆盖已通过、改分后通过、驳回、待审核、草稿；核算结果；测试1班的公示和一条待处理的异议。审核记录和审计日志都会照常写入。演示账号不要求首次改密。

- 只能写入**空库**：库里已有账号时会拒绝，所以上面的命令单独指定了一个数据库文件。启动服务时用同样的 `ZONGCE_DATABASE_URL`。
- 可调参数：`--classes`、`--students`（每班至少 10 人）、`--seed`（相同种子生成相同成绩）。

**只生成表格**，自己用管理员账号逐步导入：

```bash
uv run python scripts/gen_fake_data.py --out data/demo    # 生成 users.xlsx、college.xlsx（学号以 TEST 开头）
```

把 `users.xlsx` 导入到“批量导入账号”，再把 `college.xlsx` 导入到某个学年的“导入学院成绩表”，就能核算、排名、发布公示。`data/` 已被 `.gitignore` 排除。

## 6. 启动

```bash
uv run zongce serve            # 默认 http://127.0.0.1:8000
```

浏览器打开 <http://127.0.0.1:8000/api/v1/docs>：点右上角 **Authorize**，填入登录接口返回的 `access_token`，就能直接试用所有接口。

## 7. 前端

```bash
cd frontend && corepack enable && pnpm install && pnpm dev    # http://localhost:5173
```

前端开发服务器会把 `/api` 代理到本机后端，不需要配置跨域。页面说明和端到端测试见 `frontend/README.md`。

## 8. 一个学年的典型流程

| 步骤 | 角色 | 接口 |
|---|---|---|
| 新建学年并关联规则版本 | 学院管理员 | `POST /api/v1/years` |
| 批量导入账号（表头：学号、姓名、班级、角色） | 学院管理员 | `POST /api/v1/users/import` |
| 把随机初始密码发给学生；学生首次登录必须修改密码 | 学生 | `POST /api/v1/auth/change-password` |
| 开放申报 | 学院管理员 | `PATCH /api/v1/years/{id}/status` → `open` |
| 申报能力分、上传证明材料、提交 | 学生 | `POST /api/v1/declarations` 等 |
| 审核：通过 / 改分 / 驳回（理由必填） | 班级审核员、学院管理员 | `POST /api/v1/declarations/{id}/review` |
| 导入学院成绩表（GPA、第二课堂、公益劳动、体测、宿舍、思想品德评议） | 学院管理员 | `POST /api/v1/years/{id}/college-data/import` |
| 核算 | 学院管理员 | `POST /api/v1/years/{id}/scores/compute` |
| 查看排名、导出 Excel | 班级审核员（本班）、学院管理员 | `GET /api/v1/years/{id}/rankings[/export]` |
| 发布班级公示（默认 3 天） | 学院管理员 | `POST /api/v1/years/{id}/publications` |
| 提出异议 / 处理异议 | 学生 / 学院管理员 | `POST /api/v1/publications/{id}/appeals`、`POST /api/v1/appeals/{id}/resolve` |

## 9. 回溯测试与名单比对

- 回溯测试（M3）：`uv run zongce backtest data/history/某班.xlsx`，数据格式和结果解读见 `docs/回溯测试说明.md`。
- 名单比对（M4 基础）：审核员在前端“名单比对”页上传学院获奖名单，系统给出“可快速通过 / 人工复核”的建议，勾选确认后才会通过。`.env` 中的 `ZONGCE_AI_PROVIDER` 默认是 `none`，只支持表格（ADR 0006）。

## 10. 真实表单（只在本机）

真实数据放在 `real_data/<学年>/原始/`（已被 git 忽略）。先脱敏，泄漏数为 0 后再用于学习和统计（CLAUDE.md §11、ADR 0007）：

```bash
R=real_data/2025-2026
uv run python ai/eval/desensitize.py "$R/原始" "$R/脱敏" --private "$R/私密"   # 只打印统计；leaks 必须为 0
uv run python ai/eval/real_forms.py "$R/脱敏" --report docs/reports/real-forms-$(date +%Y%m%d).md
```

`$R/私密/` 里是对照表和密钥，不要外发；`$R/脱敏/` 也不要提交。

**人工抽样核对（计算准确率）**：

```bash
uv run python ai/eval/label_sample.py sample "$R/脱敏" "$R/标注/抽样.csv" --n 300 --mapping "$R/私密/对照表.json"
# 用 Excel 打开抽样.csv，对照原始文件逐行填写“人工_姓名 / 人工_班级 / 人工_分值”（对 / 错 / 无）、
# “人工_选项”（正确的选项编码，如 college_1；参与分填“按次”；无法确定填“无”）、“人工_漏掉人数”
uv run python ai/eval/label_sample.py score "$R/标注/抽样.csv" --report docs/reports/label-$(date +%Y%m%d).md
```

抽样表里有“真实姓名”一列，只能留在本机，不要发给别人或贴到对话里；报告只含计数。
