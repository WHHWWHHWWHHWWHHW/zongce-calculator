# 本机功能验证（2026-10-22）

- 环境：负责人的 Mac（macOS，Apple 芯片）。`bash scripts/local-demo.sh` 启动后端，后端同时提供已构建的前端，只监听 `127.0.0.1:8000`。
- 浏览器：Claude 桌面应用的内置浏览器（在同一台 Mac 上），从本机访问本机后端。
- 数据：`zongce seed-demo` 生成的合成演示库（2 个班、每班 30 人，学号以 TEST 开头），不含真实数据。
- 窗口宽度：约 575 CSS 像素（窄屏布局），另外用 375×812 检查了手机布局。

## 发现并已修复

- 名单比对页缺少页面容器，内容贴着窗口左边，标题样式也和其他页面不一致。已修复（`506c233`）。
- 首页“名单比对”卡片没有说明文字。已补上。

## 记录（未修改）

- 窄屏（≤600 px）下，表格的操作列不固定，需要横向滑动才能看到“通过 / 改分 / 驳回”。这是为了不让固定列挤占手机屏幕，属于有意的设计；如果审核员主要用手机，可以改成把操作放进展开行。
- 部分表单输入框的无障碍名称取的是占位文字（如“如：第十六届蓝桥杯省赛二等奖”），不是字段名“标题”。不影响使用，读屏软件体验略差。
