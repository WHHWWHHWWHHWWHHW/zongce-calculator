# 到梦空间与志愿章汇总的导入口径检查（2026-10-22）

- 数据：2025–2026 学年学院各部门综测汇总中的到梦空间学分汇总（3 个年级）和志愿章汇总（3 个工作表），用的是**脱敏后**的副本，只在负责人电脑上处理。本报告只有计数。
- 口径（负责人 2026-10-21 确定，CLAUDE.md §13 第 8 项）：
  - 第二课堂积分取到梦空间的“积分总和”。该列与“创新实践课程学分-积分”逐行相同；“转换后学分总和”全为 0。
  - 公益劳动次数取志愿章的“总章数”。1510 行中有 1507 行满足“总章数 = 志愿汇转化章 + 活动章数”。
- 平台的学院成绩导入已按上述口径识别这两列（`backend/src/zongce_backend/services/college.py`）：
  - Excel 的每个工作表分别识别表头；
  - 志愿章没有学号，按“班级 + 姓名”找学生，班级写法先统一（如“网合24w4”与“网合24W4”视为同一班）。

## 按“班级 + 姓名”找学生的效果

平台里还没有真实账号，这里用到梦空间名单（1289 名学生，有学号、姓名、班级）代替学院花名册来模拟。

| 志愿章数据行 | 行数 |
|---|---:|
| 合计 | 1510 |
| 按班级 + 姓名唯一找到 | 1063 |
| 姓名在到梦空间名单里，但班级不同 | 72 |
| 姓名不在到梦空间名单里（不能说明匹配有问题，只是这批学生没有到梦空间记录） | 375 |
| 同班同名、无法区分 | 0 |
| “总章数”为数值 | 1510 |

- 学生出现在到梦空间名单里的 1135 行中，**1063 行（93.7%）能唯一找到**。
- 其余 72 行姓名对得上，班级对不上。可能是转专业、班级写法不同或笔误；志愿章里有 4 个班级在到梦空间名单中没有出现。
- 导入时，这些行会逐行列入“错误”清单，**不会猜测着写入**，需要管理员核对后用学号补录，或在表中改正班级。
- 用学院的完整花名册导入时，“姓名不在名单里”的情况应基本消失，但班级不一致的行仍需人工处理。

## 结论

- 两张表可以直接通过“导入学院成绩表”导入，不需要先手工整理。
- 志愿章按班级 + 姓名匹配时，约 6% 的行因班级不一致需要人工处理。如果学院能在志愿章汇总里加上学号列，就能完全避免这个问题。
