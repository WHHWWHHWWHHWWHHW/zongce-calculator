# ADR 0004：前端基础（组件库待定）

- 状态：已采纳（组件库待负责人选定）
- 日期：2026-10-13
- 关联：CLAUDE.md §6、§8 M2、§10、§13 第 7 项

## 决定

1. **先做不依赖组件库的部分**：CLAUDE.md 规定组件库在 M2 开始时由负责人确认。无人值守期间只完成 API 客户端、登录态、路由守卫、错误处理、测试与 CI；页面在选定组件库后实现。
2. **接口类型只从 OpenAPI 生成**：`openapi-typescript` 从 `docs/api/openapi.json` 生成 `src/api/schema.d.ts`，请求用 `openapi-fetch`（同一项目，体积小、全程类型检查）。`pnpm check:api` 与后端测试一起保证“代码 → 文档 → 前端类型”三者一致。
3. **登录令牌放在 sessionStorage**：关闭浏览器即失效，存储不可用时退回内存。收到 401 自动清除登录态；修改密码后后端会让旧令牌失效，前端随之退出并要求重新登录。
4. **路由守卫是纯函数**（`src/router/guard.ts`）：未登录 → 登录页（记住目标地址）；未改初始密码 → 只能进改密页；角色不符 → 无权限页。
5. **依赖版本**：npm 上已有 TypeScript 7、Vite 8、Pinia 4、vue-router 5、Vitest 5、ESLint 10 等新的大版本。为避免与 vue-tsc、typescript-eslint 的兼容问题，选用这些包的上一个成熟大版本（TypeScript 5.9、Vite 7、Pinia 3、vue-router 4.6、Vitest 3、ESLint 9），并核对了彼此的依赖版本要求；`pnpm-lock.yaml` 锁定精确版本。升级时单独评估。

## 后果

- 选定组件库后：在 `src/views/` 用组件库重写页面，补 Playwright 端到端测试（学生申报 → 审核员通过 → 管理员导出）和 375px 宽度检查。
- 前端没有任何计分代码；分数都是字符串，只做展示。
