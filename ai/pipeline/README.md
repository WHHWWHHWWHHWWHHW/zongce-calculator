# zongce-ai：AI 辅助审核流水线

CLAUDE.md §8 M4 的基础部分。流水线只产生**建议**，不写数据库、不改分；是否通过由审核员确认（CLAUDE.md §3 第 4 条）。

```
表格行 ──解析──▶ 表单记录 ──校验──▶ 与申报匹配 ──分流──▶ 可快速通过（仍需审核员批量确认）/ 人工复核
图片、扫描件 ──OCR + 大模型（AI_PROVIDER=local|remote，尚未接入）──▶ 表单记录
```

- `normalize.py`：全角转半角、学号与数字的规范化。
- `options.py`：把“省级 一等奖”“省一”等写法对应到申报目录中某一项目的选项。
- `tables.py`：从 Excel / CSV 的行中解析出表单记录（学号、姓名、获奖等级），并给出置信度。
- `matching.py`：按学号与申报逐条匹配，判断一致、等级不符、未申报等，并分流。
- `providers.py`：`AI_PROVIDER=none|local|remote`。默认 `none`：只支持表格，图片识别明确报错，平台其余功能不受影响。
- `privacy.py`：外发前脱敏（学号做带密钥的哈希、姓名换成占位符）。

评测脚本在 `ai/eval/`，只用合成数据。
